# LampGenie Logo 设计说明

## 概念:灯神之灯 × 流水线轨道

给「我自己」(lampgenie-harness)的 logo,一句话:**灯神住在一圈流水线轨道里,你许愿,它交付**。

- **灯神之灯**= genie(许愿、数字人管家),也是 harness 的「运行时容器」:圆胖灯身承住一切。
- **两条虚线轨道 + 四个彩点**= 主流水线「代码感知 → 白板规划 → 子代理执行 → 证据验收」,沿轨道绕灯一圈,寓意任务在 harness 里循环流转、生生不息。
- **灯口青色火花**= 许愿的那一刻:一句话需求落进灯口,点亮整条流水线。火花形似终端光标 `▊`,点明 vibe coding 的本职。
- **深空蓝底**= 本地运行时的深夜工作台;金色灯身与之互补,一眼记住「一盏金灯、一圈星轨」。

## 文件清单

| 文件 | 用途 |
| --- | --- |
| `logo.svg` | 主标:512×512,深空蓝圆角方底,节点内嵌「感/规/执/验」单字 |
| `logo-light.svg` | 亮色变体:浅底 `#F4F6FB`,用于亮色主题/文档页眉 |
| `logo-mono.svg` | 单色变体:灰阶灯身 + 空心节点,用于占位图/loading/水印 |
| `logo-mark-only.svg` | 透明底纯符号(无文字、无底板),favicon 与小尺寸首选 |
| `logo-wordmark.svg` | 组合标:符号 + 「LampGenie」+ 副标语「code sense → plan → execute → verify」 |
| `preview.html` | 本地预览页:主标/变体/64·32·16px 缩放表现一页看全 |

## 使用约定

- **favicon / 小尺寸**(≤32px):用 `logo-mark-only.svg`(节点不带字,轮廓可辨);16px 下轨道虚线会退化为光环,属预期。
- **深色 UI**:用 `logo.svg` 或透明 mark;**亮色文档**:用 `logo-light.svg`,避免深色方块在白页上过重。
- 需要位图 favicon 时,由 mark-only 导出 32/16px PNG 即可(仓内未放生成脚本,保持零构建)。
- 所有文件为手写 SVG、零依赖、无外链资源,可直接内联进面板 HTML。

## 设计取舍(如实记录)

- 节点内嵌「感/规/执/验」单字在 ≥64px 可读,≤32px 冗余——因此另备 mark-only 无字版,而不是给主标做响应式。
- 灯身刻意做得圆胖低重心(而非写实阿拉伯壶),为的是 16px 缩到很小仍是一团「金色的灯」的剪影。
- 单色版保留了灰阶渐变而非纯黑:占位场景仍要能认出是这盏灯;若需纯线稿可再去渐变。
